## 3. 坑与规避（每条都有实测证据）

1. **全称放不进导航栏**。微信官方 `configuration/app.html` 未写 `navigationBarTitleText` 字数上限，但本项目作者留了证据：`pages/quiz/index.tsx:24` 把动态标题硬截成 `.slice(0, 10)`。全称 12 字，320–375pt 机型上会出省略号 → 导航栏用「内训考核」，全称放首页/我的页正文与 H5 标签页标题。
2. **`dist/` 是编译产物且带着旧品牌**（实测 `frontend/dist/app.json` 与 `dist/project.config.json` 仍是 `鱼皮AI闯关学习`）。改完必须重新构建；`project.config.json` 由 Taro 从 `frontend/` 根目录拷进 `dist`，所以只改源配置。
3. **H5 与 weapp 共用 `outputRoot: 'dist'`**，`dev:h5` 与 `dev:weapp` 不能同时开；切换前先停另一个后台任务，否则读到另一份产物。
4. **改 prompt 会同时改线上网页端**：`generate_report` 被 `report_service.py:23`（小程序）和 `assessment_service.py:168`（网页端员工复盘）共用。不改线上镜像的话，面试官打开 `exam.3hao-ui.cn:8080` 看到的 AI 报告里仍会出现「闯关」→ 见 §5 待确认 1。
5. **测试会因文案改动而红**：`test_user_api.py:26,54` 断言默认昵称 `学习者`。改默认值必须同步改断言，否则 165 绿基线破。
6. **契约字段名不能动**：`share_quote`、`total_xp`、`quiz_id` 等是前后端契约，本轮只改中文描述与展示文案。
7. **`appid` 不能动**：`frontend/project.config.json` 与 `backend/.env` 的 `WECHAT_APP_ID` 必须完全一致，否则 code2session 换 openid 失败。
8. **小程序「平台名称」不在代码里**：右上角胶囊 →「关于小程序」显示的名字来自微信公众平台，测试号是分配的，官方 sandbox 文档未提供改名入口（已查证 developers.weixin.qq.com/miniprogram/dev/devtools/sandbox.html）。本地演示时开发者工具基本不展示它，演示话术里不提即可。

### 域名访问：本轮实测推翻原假设

原计划「子域名 + 8080 免费 HTTPS，无需备案」**不成立**。`curl --resolve` 对照实测：
`.cn` 域名（含 `exam.3hao-ui.cn`）在 8080 端口一律被阿里云拦成
403 + `Server: Beaver` + `Non-compliance ICP Filing`；IP 直连与非 `.cn` 的 Host 均 200。
**拦截按域名备案状态判定，与端口无关。** 且 `exam.3hao-ui.cn` 连 A 记录都尚未创建。

当前可用地址仍是 `http://<服务器公网IP>:8080`。要上域名必须先 ICP 备案
（个人备案 7~20 天，按量付费实例需先转包年包月才拿得到备案服务码）；
非 `.cn` 域名当前不拦属灰色地带，厂商随时可收紧，不宜作长期方案。
详细对照表与结论见 [服务器部署操作手册 §9](./服务器部署操作手册.md)。
